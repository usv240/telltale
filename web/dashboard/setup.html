Configure a site from one reference photo

1. Load a frame from the camera. 2. Draw STABLE polygons on ground that cannot move (bedrock, buildings, road off the slide). 3. Draw TARGET zones on the slope you care about. 4. Set the scale from two points of known separation or from an E2 figure. 5. Export site.json and send it with the first epoch. Click to add vertices, double-click to close a polygon, Escape to cancel.
