    Displacement series

    Median displacement of valid subsets in the zone, with ±1σ (robust) band. Nothing is interpolated across unusable epochs.

    How to read this

    Each dot is one epoch. A flat line is a quiet slope; a straight slope is steady creep; a curve bending upward is acceleration. The red vertical line marks the onset of acceleration. Gaps are unusable epochs (blind, blurred, camera event): they widen the uncertainty and are never filled in.

    Inverse velocity

    After the onset of acceleration, 1 / velocity falls toward zero. The line's time-axis intercept is the forecast failure time; the shaded band is the bootstrap and ensemble window.

    How to read this

    This is the physics. For creep-type failures, one divided by velocity falls along a straight line and reaches zero at failure (Fukuzono 1985). The dashed line is the fit from the onset of acceleration, the red marker is its time-axis intercept, and the shaded band is the forecast window from a bootstrap of the fit plus the disagreement between three fitting methods. The forecast is always a window, never a single time.

    Supervising agent

    How to read this

    When the instrument raises an event (acceleration, camera event, quality drop), a bounded agent investigates by calling OpenCV 5 again: re-measuring against alternate references, re-estimating camera motion, checking sharpness and direction coherence. Each result changes what it calls next. It can page a person or close the event as a false alarm; it can never send a public alert. Every tool call is logged here.
